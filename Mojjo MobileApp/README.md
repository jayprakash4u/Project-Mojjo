# Mojjo MobileApp

Welcome to the **Mojjo Mobile Application** workspace.

This mobile application connects with the **Mojjo .NET 10 Backend** API (`/api/v1/...`) for ultra-fast grocery, alcohol, snacks, cold drinks, and tobacco delivery.

---

## 📱 Features & Capabilities
- **Catalog Browsing & Search**: Real-time category navigation, flash deals, and keyword search.
- **Cart & Fast Checkout**: Streamlined mobile ordering with immutable price snapshots.
- **Payment Integration**: Native digital wallet checkout with **eSewa** & **Khalti**.
- **Live Order Tracking**: Real-time delivery status updates and courier location tracking.
- **Loyalty Rewards**: Mojjo coins accumulation and redemption.

---

## 🌐 API Configuration
- **Backend API Base URL**: `http://10.0.2.2:5177/api/v1` (Android Emulator) / `http://localhost:5177/api/v1` (iOS Simulator / Local)
- **API Documentation (Swagger)**: `http://localhost:5177`
